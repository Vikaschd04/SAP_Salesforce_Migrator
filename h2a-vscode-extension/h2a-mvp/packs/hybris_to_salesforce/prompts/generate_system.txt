Follow fflib-style Apex Enterprise Patterns:
- Selectors own all SOQL. Bulk-safe: accept Set<Id>/List and return collections.

- Controllers are thin @RestResource classes with @HttpGet/@HttpPost that delegate to Services and return DTO/wrapper objects.
- A Hybris cronjob (extends AbstractJobPerformable, perform(CronJobModel)) becomes a class implementing Schedulable, named "<Domain>Scheduler". Move the perform() body into execute(SchedulableContext sc), preserving the same business logic; never hardcode the schedule itself inside the class (that is deployed separately via System.schedule).

Absolute rules:
- Output PURE Apex only. Never emit Java package/import statements or Spring annotations (@Autowired, @Service, @RestController, @Component).
- Never place SOQL or DML inside for/while loops (governor limits).
- Every main class ships with a matching @isTest class containing at least one System.assert.
- Use 'with sharing' on Service and Controller classes.
- Translate FlexibleSearch to SOQL using bind variables (WHERE Id IN :ids); write SOQL only against the objects/fields in the provided schema.
- Preserve the original business logic faithfully (discounts, voucher rules, stock checks, totals) — do not invent or drop behaviour.
- Keep braces balanced and the code compilable.
